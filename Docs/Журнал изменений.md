Сюда записывается всё, что меняется в проекте: что сделано, зачем и как проверено. Новые записи добавляются сверху.

## 2026-11-20 · Этап 7. Навигация и меню

При первом входе открываются три карточки правил со свайпом и кнопками. Настройка звука сохраняется между запусками. Чтобы начать партию из меню с настройками по умолчанию, достаточно выбрать режим и нажать «Начать игру».

В режиме с ботами можно задать имя и выбрать 1–5 соперников. На одном устройстве можно собрать стол из 2–6 участников и добавить ботов. Выход из текущей партии требует подтверждения. После завершения игры можно повторить партию с тем же составом или вернуться в меню. Экран передачи устройства предусмотрен этапом 8.

В Unity прошли 162 из 162 EditMode-тестов проекта, включая партию двух людей и бота до победителя. Браузерный звук и свайп на телефоне предстоит проверить в ручной WebGL-сборке.

## 2026-11-20 · Этап 6. Сессия и серый стол

Boot запускает локальную партию одного игрока с тремя ботами. Сессия управляет ходами и таймером ботов, TablePresenter показывает руку, ход, обвинение, раскрытие карт и победителя. В сцене назначен Inter SDF.

## 2026-11-19 · Этап 5. Боты

Всё в `LiarsBar.Core` (`Core/Bots`), без ссылок на Unity. Ассеты профилей — в Infrastructure/Content.

### Код

| Файл | Что внутри |
| --- | --- |
| `Core/Bots/BotProfile.cs` | `BotProfile` (обычный `[Serializable]`-класс): знание по сложности 1/2/3, порог обвинения, +0,05 к порогу за каждый сделанный выстрел, шанс подмешать ✗, базовая вероятность лжи 0,35 и модификаторы (+0,15 при ≤ 1 карте у сыгравшего, +0,10 за ход из 2 карт). Готовые `Cautious`, `Brazen`, `Expert` по таблице из документа MVP, `Validate()`, `Clone()` |
| `Core/Bots/IBotStrategy.cs` | `IBotStrategy.Decide(PlayerView, BotProfile, IRandom)` → `IGameAction` |
| `Core/Bots/FactKnowledge.cs` | `IFactKnowledge` + `FactCatalog` (справочник фактов из `ISubjectProvider`, «эрудиция» бота). `BotRecall.Roll(botKey, factId)`: детерминированное число [0, 1) из хэша FNV-1a + перемешивание (`string.GetHashCode` не годится: он разный в разных рантаймах). `BotKey(соль, место)` |
| `Core/Bots/HeuristicBotStrategy.cs` | Алгоритм из раздела 6. «Лжец!»: принудительно → обвиняет; иначе P(ложь) = 1 − П(1 − pᵢ) больше порога → обвиняет. Знает карту → pᵢ = 0 или 1, не знает → база с модификаторами. Ход: одна ✓ (+ самая сложная ✗ с шансом профиля), если ✓ нет — самая сложная ✗. Знание = `Roll(BotKey(соль, место), факт) < KnowChance(сложность)`, поэтому бот не «забывает» факт. Соль задаётся на партию |
| `Core/Bots/BotSimulation.cs` | `BotSimulation.Run(subjects, profiles, matches, players, seed)` → `BotSimulationResult`: среднее/мин/макс раундов, доля верных обвинений, принудительные обвинения, доля ✗ среди сыгранных карт, победы по профилям (доля партий и на одно место). Профили садятся по кругу со сдвигом на каждую партию. Пригодится для баланса на этапе 12 |
| `Infrastructure/Config/BotProfileAsset.cs` | ScriptableObject-обёртка (`Profile` отдаёт копию), предупреждения из `Validate()` в `OnValidate` |
| `Content/Configs/Bot_cautious.asset`, `Bot_brazen.asset`, `Bot_expert.asset` | Три профиля для инспектора |

**Что видит бот.** Состояние партии — только свой `PlayerView`. Справочник фактов — это «знания в голове»: правдивость карты на столе бот берёт оттуда, только если «знает» факт.

### Тесты

- `Core.Tests/BotTests.cs`: профили совпадают с таблицей документа; рост порога; `BotRecall` детерминирован, равномерен и независим у разных ботов; принудительное обвинение; на первом ходу раунда бот не обвиняет; известная ложь / известная правда; базовая оценка и модификаторы (0,35 / 0,6975 / 0,50); порог с выстрелами; выбор ✓, подмешивание самой сложной ✗, ограничение `maxCardsPerPlay`; только ✗ → самая сложная; знание стабильно; не свой ход → исключение; 40 партий ботов × 2–6 игроков на синтетике; один seed даёт тот же результат.
- `Content.Tests/BotBalanceTests.cs` (**«Готово, когда» этапа**): 200 партий на настоящем контенте для 4, 2 и 6 игроков доигрываются. Отчёт — в консоль и `Temp/liarsbar_bots.txt`.
- **Результат: 129 / 129 пройдено** (106 старых + 23 новых, EditMode, 9 с).

### Отчёт симуляции (seed 2026, 200 партий, профили до балансировки)

| Игроков | Раунды (ср. / мин / макс) | Верных обвинений | ✗ среди карт | Победы: Осторожный / Наглый / Знаток (доля партий) |
| --- | --- | --- | --- | --- |
| 4 | 11,1 / 3 / 22 | 99,1 % | 29,4 % | 40,0 % / 5,0 % / 55,0 % |
| 2 | 4,0 / 1 / 10 | 99,1 % | 34,3 % | 31,5 % / 22,5 % / 46,0 % |
| 6 | 18,4 / 7 / 29 | 98,2 % | 27,4 % | 48,5 % / 4,5 % / 47,0 % |

### На заметку (к балансу на этапе 12)

- Число раундов на 4 игроков (11,1) уже в цели 8–14.
- **Знаток выигрывает 55 %** партий на 4 игроков (цель — не больше 50 %), **Наглый почти не выигрывает** (5 %).
- **99 % обвинений верные — боты слишком «ясновидящие».** Причина в самом алгоритме: бот кладёт 2 карты только когда подмешивает ✗, а ✗ без ✓ — только когда ✓ закончились. Ход из 2 карт поэтому всегда содержит ложь, и оценка 0,6975 выше любого порога. Одиночную незнакомую карту (0,35) не обвиняет почти никто. Человек тоже быстро заметит, что «2 карты = враньё». Варианты: иногда класть 2 ✓, иногда класть одну ✗ при наличии ✓, понизить `TwoCardsBonus`, поднять базу для незнакомых карт у Наглого.

- **Исправлено:** архив пересобран через Python `zipfile` с путями через `/`. `index.html` лежит в корне архива. Сама сборка не менялась.
- Совет на будущее: архивы для itch.io собирать скриптом с `/` или через 7-Zip, а не через `Compress-Archive` в PowerShell 5.1.
