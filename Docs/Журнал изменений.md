### Сцена и скрипт смоук-теста

- Отдельная сборка `Assets/_Project/Networking/SmokeTest/LiarsBar.Networking.SmokeTest.asmdef` (Photon, TMP, uGUI, Input System, Newtonsoft). Отдельная, чтобы зависимости тестового UI не попали в основную `LiarsBar.Networking`.
- `PhotonSmokeTest.cs`, будущая основа `RoomService` (этап 13):
  - сразу после старта подключается к Photon (`ConnectUsingSettings`), ник `Player-NNN`;
  - **Create** создаёт невидимую комнату на 6 мест с 4-буквенным кодом без похожих символов (без O и I); если код занят, пробует другой, до 5 попыток;
  - **Join** входит по коду; ошибки выводятся понятным текстом: «Room not found», «Room is full», «Game already started»;
  - показывает список игроков с пометками `[host]` и `(you)`, состояние подключения, регион и RTT;
  - **Ping** отправляет `RaiseEvent` (код 100, надёжная доставка) с JSON через Newtonsoft; каждый получатель отвечает Pong (код 101) лично отправителю, а отправитель видит время ответа. Заодно это проверяет, что Newtonsoft работает в WebGL-сборке;
  - UI строится из кода: Canvas Scaler 1080×1920, `InputSystemUIInputModule`. Тексты на латинице, потому что в стандартном шрифте TMP нет кириллицы.
- Сцена `Assets/_Project/Networking/SmokeTest/PhotonSmokeTest.unity` в Build Settings не добавлена, собирается отдельной командой.

### Результат проверки в редакторе

- Name server (`ns.photonengine.io`, WSS) **доступен**: клиент получил адрес мастер-сервера региона `eu` (`GCAMS1055.exitgames.com`).
- Подключение к мастер-серверу **не проходит**: TLS-рукопожатие обрывается (`UNITYTLS_INTERNAL_ERROR`).
- Диагностика из системы (`curl`, `openssl`): на порту 443 всех хостов `*.exitgames.com` отвечает промежуточный узел провайдера (`Via: 1.0 middlebox`) с редиректом на `guvenliinternet.turktelekom.com.tr`. Это фильтр Türk Telekom «Güvenli İnternet». Хосты `*.photonengine.io` при этом проходят.
- **Вывод:** код и настройки Photon рабочие, блокирует сеть разработчика. Обойти в коде нельзя: у игровых серверов Photon нет адресов вне `exitgames.com`. Игроков в других сетях это не касается, но проверяющий в сети с таким же фильтром не подключится, и это нужно вписать в известные ограничения.

### Первая ручная проверка: две проблемы

**1. В редакторе: Create падает с ошибкой `32752: Unsupported Plugin`.**
- Подключение к мастер-серверу на этот раз прошло, то есть сеть уже пропускает Photon.
- Код 32752 — это `ErrorCode.PluginReportedError`: создание комнаты отклонил серверный плагин приложения. Сам клиент плагинов не запрашивает (`RoomOptions` без `Plugins`).
- Значит, AppId в `PhotonServerSettings → App Id PUN` взят из приложения другого типа (Fusion / Quantum / Voice / Chat). Серверный плагин такого приложения отклоняет комнаты PUN.
- **Решение (делает владелец аккаунта Photon):** создать в Photon Dashboard новое приложение с типом **Multiplayer Game → SDK «PUN»** и вписать его App ID в `App Id PUN`. Код менять не нужно.

**2. На itch.io серый экран.**
- Архив `SmokeTest.zip` был собран средствами Windows, и пути внутри записались через `\` (`Build\SmokeTest.wasm.unityweb`).
- itch.io распаковывает архивы на Linux, где `\` не считается разделителем папок. В итоге папки `Build/` нет, и загрузчик Unity не находит файлов.
- **Исправлено:** архив пересобран через Python `zipfile` с путями через `/`. `index.html` лежит в корне архива. Сама сборка не менялась.
- Совет на будущее: архивы для itch.io собирать скриптом с `/` или через 7-Zip, а не через `Compress-Archive` в PowerShell 5.1.
