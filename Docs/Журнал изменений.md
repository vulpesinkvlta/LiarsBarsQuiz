**Статистика для номинаций:** `UncaughtLies` растёт, когда следующий игрок кладёт карты поверх хода с ✗ вместо обвинения; `CorrectAccusations` / `WrongAccusations` — при обвинении; `ShotsSurvived` — при холостом выстреле; `CardsPlayed` — при каждом ходе.

### Тесты (`Core.Tests`)

- `DealerTests`: размер руки и состав на 2–6 игроков × 100 seed, без дублей; «тесный» предмет (6 ✓ на 6 игроков) с одной попыткой пересдачи; `CanDeal`.
- `MatchStartTests`: старт и первый ход, случайный первый игрок, 1 и 7 игроков отклоняются, нехватка контента, повторный старт, предметы не повторяются.
- `MatchTurnTests`: переход хода, пропуск игрока с пустой рукой, принудительное обвинение (и при пустых руках у всех, и когда карты остались только у сыгравшего), непойманная ложь.
- `AccusationTests`: верное и неверное обвинение, ход из ✓+✗, кто начинает новый раунд, выбывание и пропуск выбывшего, конец партии.
- `ValidationTests`: 9 видов невалидных действий не меняют состояние (сверка отпечатка) и не дают событий.
- `PlayerViewTests`: в снимке только своя рука, у карт на столе нет пометок, в публичных типах нет `Fact`/`Hand`/`Revolver`/позиции пули, снимок зрителя.
- `MatchSimulationTests` (**«Готово, когда» этапа**): 60 партий × 2–6 игроков случайными допустимыми ходами, выбранными только по `PlayerView`, до `MatchEnded` без исключений и зависаний; инварианты на каждом шаге; каждый раунд заканчивается ровно одним обвинением; один seed даёт одну и ту же партию.
- **Результат: 76 / 76 пройдено** (EditMode, 3,5 с).

### На заметку

- Хелпер тестов назван `NewEngine`, а не `Engine`: внутри `LiarsBar.Core.Tests` имя `Engine` совпадает с пространством имён `LiarsBar.Core.Engine` (ошибка CS0118).
- Фаза `Resolving` внутри `Apply` промежуточная: наружу состояние выходит уже в `AwaitingAction` (новый раунд) или `Ended`.

### Первая ручная проверка: две проблемы

**1. В редакторе: Create падает с ошибкой `32752: Unsupported Plugin`.**
- Подключение к мастер-серверу на этот раз прошло, то есть сеть уже пропускает Photon.
- Код 32752 — это `ErrorCode.PluginReportedError`: создание комнаты отклонил серверный плагин приложения. Сам клиент плагинов не запрашивает (`RoomOptions` без `Plugins`).
- Значит, AppId в `PhotonServerSettings → App Id PUN` взят из приложения другого типа (Fusion / Quantum / Voice / Chat). Серверный плагин такого приложения отклоняет комнаты PUN.
- **Решение (делает владелец аккаунта Photon):** создать в Photon Dashboard новое приложение с типом **Multiplayer Game → SDK «PUN»** и вписать его App ID в `App Id PUN`. Код менять не нужно.

**2. На itch.io серый экран.**
- Архив `SmokeTest.zip` был собран средствами Windows, и пути внутри записались через `\` (`Build\SmokeTest.wasm.unityweb`).
- itch.io распаковывает архивы на Linux, где `\` не считается разделителем папок. В итоге папки `Build/` нет, и загрузчик Unity не находит файлов.
- **Исправлено:** архив пересобран через Python `zipfile` с путями через `/`. `index.html` лежит в корне архива. Сама сборка не менялась.
- Совет на будущее: архивы для itch.io собирать скриптом с `/` или через 7-Zip, а не через `Compress-Archive` в PowerShell 5.1.
