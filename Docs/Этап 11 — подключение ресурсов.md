# Этап 11. Как поставить свои картинки, звук и эффект выстрела

Все назначения хранятся в одном файле — `Assets/_Project/Content/BarTheme.asset`. Он уже подключён к компоненту Bootstrap в сцене `Assets/_Project/Bootstrap/Boot.unity`. Можно заполнять по одному полю. С пустыми полями стол использует цветные панели и штатную анимацию барабана, а соответствующие звуки пропускаются.

## Первая замена за минуту

1. Останови Play Mode. В окне **Project** открой **Assets → _Project → Content**. Можешь создать здесь папки **Art** и **Audio** для своих файлов.
2. Перетащи PNG сукна из проводника в Art. Выдели его в Project. В Inspector выставь **Texture Type → Sprite (2D and UI)** и **Sprite Mode → Single**, нажми **Apply**.
3. Выбери **BarTheme** в Project. Перетащи импортированный спрайт в поле **Felt**. Для второго способа нажми кружок справа от поля и выбери спрайт по имени.
4. Сохрани проект (**File → Save Project**), открой сцену **Boot**, нажми **Play** и начни партию с ботами. Сукно появится под сыгранными картами. Если рисунок слишком тёмный, осветли **Panel Color** — этот цвет умножается на цвет картинки и используется также другими панелями.

## Какие картинки подготовить

| Поле Inspector | Что положить | Где проверить |
|---|---|---|
| Backdrop | Фон бара без надписей, с запасом по краям | Фон игрового стола, растягивается в размер экрана |
| Felt | Текстура сукна с неброским центром | Область последнего хода |
| Card | Бланк карты с пустым центром | Рука и сыгранные карты. Текст, отметка и подсветка добавляются игрой |
| Portrait | Квадратный PNG силуэта с прозрачностью | Левый нижний угол каждого места. Один портрет используется для всех игроков |
| Revolver | Квадратный PNG барабана, ось вращения в центре изображения | После раскрытия карт вместо шести индикаторов вращается спрайт |
| Shot Flash | PNG вспышки с прозрачностью | На короткое время окрашивает фон анимации при попадании. Тряска остаётся встроенной |

Для каждого PNG повтори импорт из шага 2. Для карточки и сукна лучше подходит рисунок без тонкой рамки — прямоугольники меняют пропорции при повороте экрана. Поля принимают спрайты. Для эффекта выстрела достаточно одного кадра, отдельный Animator или prefab собирать не нужно.

## Как подключить семь звуков

1. Импортируй короткие WAV или OGG в папку Audio. Выдели клип и послушай его в предпросмотре Inspector. Для публичной сборки план предусматривает CC0. Сохрани ссылку на источник и лицензию рядом с оригиналами.
2. Выбери BarTheme и перетащи клипы в поля ниже. Имена файлов произвольные. Чтобы быстро проверить настройку, сначала назначь только **Click** и нажми «Войти в бар».
3. Запусти матч. В меню переключатель звука управляет всеми семью сигналами и запоминает выбор.

| Поле | Момент воспроизведения |
|---|---|
| Click | Нажатие обычной кнопки интерфейса |
| Cards | Начало раздачи или анимации сыгранных карт |
| Liar | Появляется обвинение «Лжец!» |
| Spin | Начало вращения барабана |
| Empty | После паузы выпала пустая камора |
| Shot | После паузы выпал выстрел |
| Victory | Открылся итоговый экран партии |

## Цвета и шрифт

В BarTheme цвет **Background** тонирует фон, **Panel Color** — панели, **Panel Light** — карты и кнопки. **Highlight** отмечает активного игрока, **Selected** — выбранную карту, **Dead** — выбывшего. **Text** и **Text Dim** задают основной и приглушённый текст, **Overlay** — затемнение под окнами. После смены палитры проверь выбранную карту и отключённую кнопку.

Для своего шрифта импортируй TTF/OTF с кириллицей. В Project нажми на него правой кнопкой и выбери **Create → TextMeshPro → Font Asset**. Назначь полученный TMP Font Asset в поле **Font** темы. Проверь буквы «ё», «Й» и символы ✓/✗ на карте. Если символ отображается квадратом, используй шрифт с этим глифом либо настрой fallback в TMP Font Asset. Пустое поле Font использует шрифт, назначенный в Bootstrap.

## Проверка перед сборкой

- В окне Game задай сначала 1920×1080, затем 390×844. Поменяй размер во время партии. На широком экране действия справа от стола, на вертикальном — под рукой, карты руки в две колонки.
- Проверь полную руку при игре вдвоём и шесть мест при максимальном составе. Сыграй длинный факт, раскрой его, проверь текст и отметку. В hot-seat перед подтверждением следующий игрок должен видеть заставку.
- Проверь оба исхода рулетки, итог партии и «Сыграть ещё». В WebGL сначала нажми «Войти в бар», затем проверь звук. Если клип молчит, проверь переключатель в меню, громкость вкладки и наличие клипа в поле темы.
- Чтобы заменить файл, останови игру, назначь новый ресурс в то же поле, сохрани и запусти Boot снова. Чтобы вернуть заглушку, очисти поле через выбор **None**. Для уже опубликованной версии потребуется новая WebGL-сборка.
